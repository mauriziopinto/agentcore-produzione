Lab 0 · Ripartenza

Ricrei TelcoCare com'era alla fine del primo workshop. Dieci minuti, quasi tutti di attesa.

Gli ambienti sono nuovi, quindi TelcoCare non c'è più. Uno script lo ricostruisce: Runtime con Memory, Gateway con il CRM, regole Cedar, Code Interpreter e Browser. Mentre lavora, chi conduce il workshop presenta i messaggi chiave della giornata.

  1. Clona il repository del workshop. È privato: prima accetta l'invito GitHub che hai ricevuto per email. Come password, Git vuole un personal access token di GitHub, come nel primo workshop.

    git clone https://github.com/mauriziopinto/agentcore-produzione.git ~/agentcore-produzione
cd ~/agentcore-produzione

  2. Imposta la regione e controlla l'ambiente.

    export AWS_REGION=us-east-1
grep -q AWS_REGION ~/.bashrc || echo 'export AWS_REGION=us-east-1' >> ~/.bashrc
bash scripts/verifica_ambiente.sh

  3. Ricostruisci TelcoCare.

    bash scripts/prepara_base.sh

    Lo script fa due deploy: il primo crea Runtime, Memory e Gateway, il secondo aggiunge le regole Cedar, che devono conoscere l'indirizzo del Gateway. Nelle nostre prove è durato 9 minuti e mezzo.

    Cosa dovresti vedere Alla fine, la risposta a una domanda di prova sulla fattura di Giulia: 
    [strumento] crm___get_fatture
Ciao Giulia, la tua fattura di ottobre 2026 (n. F2026-1021) è di 29,98 euro e risulta ancora da pagare. ...
TelcoCare è pronto. Da qui in poi lavora nella cartella /home/participant/agentcore-produzione/TelcoCare.

  4. Entra nella cartella del progetto. Da qui partono tutti i comandi dei lab.

    cd ~/agentcore-produzione/TelcoCare
Cosa c'è di diverso dal primo workshop

Le regole Cedar sono due. La prima consente sempre le letture e i ticket. La seconda consente gli accrediti fino a 100 euro, non più 20: è il tetto massimo che nessuno può superare. Nel Lab 3 aggiungiamo un livello in mezzo, fra 20 e 100 euro, in cui decide una persona.

Se lo script si ferma

Rilancialo solo dopo aver tolto quello che ha creato: cd ~/agentcore-produzione/TelcoCare && bash ../scripts/pulizia.sh && cd .. && rm -rf TelcoCare. Poi bash scripts/prepara_base.sh.
