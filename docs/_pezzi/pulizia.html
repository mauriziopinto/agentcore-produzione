Pulizia

Cancelli tutto quello che hai creato durante il workshop, anche nei lab da fare da soli. Circa dieci minuti, quasi tutti di attesa.

  1. Dalla cartella del progetto lancia lo script di pulizia.

    cd ~/agentcore-produzione/TelcoCare
bash ../scripts/pulizia.sh

    Lo script cancella, in ordine:

    • lo stack AgentCore-TelcoCare-default, con tutti i Runtime (agent, clienti, fatturazione), la Memory, il Gateway, le regole, gli endpoint e le valutazioni;
    • lo stack telcocare-crm, con la Lambda e la tabella degli accrediti;
    • il pool Cognito del Lab 7, il guardrail del Lab 8 e gli allarmi del Lab 10, se li hai creati;
    • i gruppi di log che restano dopo le risorse, cioè quelli con TelcoCare o telcocare nel nome.

  2. Controlla che non sia rimasto nulla.

    aws cloudformation describe-stacks --query "Stacks[?contains(StackName,'TelcoCare') || contains(StackName,'telcocare')].StackName"
aws bedrock-agentcore-control list-agent-runtimes --query "agentRuntimes[?contains(agentRuntimeName,'TelcoCare')].agentRuntimeName"
aws bedrock-agentcore-control list-memories --query "memories[?contains(id,'TelcoCare')].[id,status]"
aws cognito-idp list-user-pools --max-results 20 --query "UserPools[?Name=='telcocare-clienti'].Id"
aws bedrock list-guardrails --query "guardrails[?name=='telcocare-dati-personali'].id"
    Cosa dovresti vedere Cinque liste vuote, []. Una Memory può restare qualche minuto nello stato DELETING: sparisce da sola.
Cosa resta

Restano lo stack CDKToolkit, creato al primo deploy, e l'impostazione di CloudWatch Transaction Search: non riguardano solo questo workshop, quindi lo script non li tocca. Restano anche i file nel tuo ambiente.
